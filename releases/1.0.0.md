# PlexonSkills 1.0.0 Candidate

This build is the first complete Core-native PlexonSkills implementation for Paper 26.2 / Java 25.

## Included

- 13 required skill domains.
- Core 2.0 block routing/origin integration.
- Precomputed XP progression and anti-exploit policies.
- In-memory profiles + coalesced SQLite persistence.
- Public API/events, GUI, commands, diagnostics and PlaceholderAPI.
- SHADOW/PRIMARY mode infrastructure and safe migration discovery workflow.

## Candidate limitation

The repository does not include administrator-owned mcMMO data or a production-like server. Therefore migration execution, SHADOW comparison, PRIMARY staging, Spark benchmarks and the 30-minute soak cannot be truthfully claimed by CI. The candidate intentionally refuses to guess an unknown mcMMO schema.

Use this prerelease for staging. Promote the same release line to stable `v1.0.0` only after `docs/STAGING.md` is satisfied.
