# PlexonSkills 2.0.0

> Stable release target. Do not publish this release until every gate in `docs/STAGING.md` has actually passed.

PlexonSkills 2.0.0 is the Phase 2 premium-tier product rebuild for Paper 26.2, Java 25 and PlexonCore 2.0.4.

Stable scope includes the complete premium GUI hierarchy, 13-skill active abilities, milestone-derived passives, asynchronous leaderboards, expanded PlaceholderAPI, premium administration, provenance-aware anti-exploit behavior, migration-safe Core SQLite persistence and the stabilized public API/event contract.

## Stable-only certification requirements

Before creating `v2.0.0`, record real PASS evidence for:

- manual player/admin GUI and navigation matrix;
- representative 1.x/prerelease database migration rehearsal;
- restart/reload/logout persistence validation;
- ability/milestone runtime matrix;
- PlaceholderAPI/API integration checks;
- Spark baseline/comparison under progression/GUI load;
- minimum 30-minute soak with memory/task/write-queue checks.

CI success alone is insufficient for stable certification.

Until all items above pass, use the latest immutable `v2.0.0-rc.*` prerelease and keep stable `v2.0.0` unpublished.
