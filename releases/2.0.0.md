# PlexonSkills 2.0.0

PlexonSkills 2.0.0 is the Phase 2 premium-tier product rebuild targeting Paper 26.2, Java 25 and PlexonCore 2.0.4.

This release line evolves the 1.0 Core-native candidate into a complete player-facing progression product while preserving the safe Core-owned event/persistence architecture.

## Planned premium scope

- premium `/skills` navigation and per-skill detail flows;
- player profile, progression roadmap, leaderboards and statistics views;
- real configurable active abilities and cooldown states;
- meaningful milestone/reward progression;
- PlexonTools-derived MiniMessage presentation grammar;
- stronger anti-exploit policy and diagnostics;
- safe PlexonSkills 1.x -> 2.0 schema migration;
- PlexonCore 2.0.4 lifecycle baseline;
- immutable JAR + SHA-256 release provenance.

## Runtime certification

Runtime/staging evidence must not be fabricated. Any production-like Spark, soak, migration and manual GUI acceptance gates not executed at release-candidate time must be explicitly reported as `NOT EXECUTED` until verified.
