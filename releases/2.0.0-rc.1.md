# PlexonSkills 2.0.0 RC1

PlexonSkills 2.0.0 RC1 is the production-like Phase 2 premium-tier release candidate for Paper 26.2, Java 25 and PlexonCore 2.0.4.

## Included

- premium session-safe `/skills` and admin GUI product layer;
- 13-skill active ability runtime with shared expiration coordination;
- milestone progression and differentiated passive scaling;
- asynchronous stale-safe leaderboards;
- expanded PlaceholderAPI and immutable public API 2.0 views;
- anti-exploit/provenance overhaul;
- native 1.x/prerelease -> 2.0 transactional database migration with mandatory backup and canonical-XP invariants;
- tracked logout/shutdown persistence barrier and reload rollback hardening;
- expanded migration/API/concurrency regression tests;
- complete operational/configuration/commands/PAPI/migration/staging documentation.

## Migration safety

A recognized legacy PlexonSkills database is validated and backed up before migration. The 2.0 migration preserves canonical `(player_uuid, skill, total_xp)` rows and recalculates only derived stored levels using the configured curve. Unknown or malformed legacy state is refused rather than guessed.

Read `docs/MIGRATION_2_0.md` before deploying over an existing 1.x/prerelease database.

## Not stable-certified

The following PlexonCraft runtime gates have **not** been executed as part of automated CI and remain:

```text
manual premium GUI/navigation matrix: NOT EXECUTED
real production-like legacy migration: NOT EXECUTED
Spark baseline/comparison:             NOT EXECUTED
runtime persistence/reload matrix:      NOT EXECUTED
30-minute soak:                         NOT EXECUTED
```

Therefore RC1 is intentionally published as a GitHub **prerelease**. It must not be relabeled or republished as stable `v2.0.0` until every required gate in `docs/STAGING.md` has actually passed.

## Deployment recommendation

Use a staging/production-like server first. Back up the complete PlexonSkills data directory, verify the JAR checksum, run the migration rehearsal if applicable, inspect `/skillsadmin diagnostics`, then execute the manual matrix in `docs/STAGING.md`.
